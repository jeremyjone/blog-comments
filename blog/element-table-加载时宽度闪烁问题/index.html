element table 加载时宽度闪烁问题

发布于 2023-02-15 09:48:52 · 1 分钟 · 标签：

每次加载 element 的 table，当在 tabs 标签中切换时，table的宽度都会从一个较小值展开，看着就是闪烁，体验非常不好。

看了一下，我这里在它内部 table 标签不知道为什么要添加一个 style="width:320px" 的固定值，直接替换了就可以：

table {
    width: 100% !important;
}

嗯，使用起来没什么副作用。
