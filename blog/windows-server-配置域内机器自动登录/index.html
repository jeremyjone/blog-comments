Windows Server 配置域内机器自动登录

发布于 2019-07-04 14:25:38 · 1 分钟 · 标签： windows Windows Server 组策略 自动登录

有时我们需要一些域内机器可以自动登录，普通的方法可以去掉密码，但是去掉密码的方式并不能完全达到自动登录的效果，同时也降低了安全性。

通过配置注册表信息，也可以做到自动登录，同时也可以带密码自动登录。

在域服务器中打开组策略管理，依次找到 计算机配置 -> 首选项 -> Windows设置 -> 注册表，在打开的注册表管理中添加如下信息：

其中， AutoAdminLogon是自动登录配置选项，1为自动，0为非自动； DefaultDomainName是域名，我的服务器配置是AD01，所以直接填AD01； DefaultUserName是用户名，这里需要使用域内账户； DefaultPassword是该账户的密码。

这样配置后，电脑重启会自动使用该账户尝试登陆，如果信息错误，则登陆失败，如果正确，则登陆成功，从而实现无人管理的自动开机登陆。

注意：

该方法我曾经在 用户配置 中使用，并没有效果，我起初以为这种方法并不对，于是查找其他方案，但是后来觉得，好像用户配置需要登录后才会生效，于是将其导入 计算机配置 中重新尝试，成功~ 所以，这个小坑需要注意。
