Windows Server 2019安装与配置（一）

发布于 2019-04-17 17:14:27 · 1 分钟 · 标签：

最近公司配置全新的服务器，我边配置边顺手记录了一下，方便今后参考。

下载安装包，然后启动。 按需要选择，这里选择带界面的数据中心版本，其实我特别好奇，谁会安装windows而不装界面？那为啥不去Linux。。。Windows的CMD根本没法用哈！

安装速度很快，不到5分钟就可以完成。

完成后会自动重启。

重启后就看到熟悉的界面了。

这里有个坑，安装完成后可能网卡（获其他内置硬件）没有驱动。。。因为Windows的安全因素，一般主板自带的Inter网卡，在Windows Server版本的系统上都无法找到对应驱动。 如果出现这个问题，不要紧张，解决方案参看：☞Windows Server 无法安装网卡驱动的解决方案

激活： 在cmd中依次输入：

slmgr /upk
slmgr /ipk WMDGN-G9PQG-XVVXX-R3X43-63DFG
slmgr /skms zh.us.to
slmgr /ato

注意替换相应版本的秘钥：

Windows Server 2019 Datacenter  WMDGN-G9PQG-XVVXX-R3X43-63DFG
Windows Server 2019 Standard    N69G4-B89J2-4G8F4-WWYCC-J464C
Windows Server 2019 Essentials  WVDHN-86M7X-466P6-VHXV7-YY726

运行完如下：

`slmgr /xpr`是查询激活过期时间的命令。

先给计算机改个名字（随意，改完重启开始配置，我习惯这样。） 安装完成，我们可以开始配置。
